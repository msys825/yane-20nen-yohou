# 精度の確かめ用データ

- （公開版には含めない）屋根台帳_記録表.csv：練馬区50軒について、東京ソーラー屋根台帳（公益財団法人東京都環境公社）に表示された予測値を書き写したもの。数値の著作権は同公社にあり、比較の目的でのみ使う。公開する場合は出典を明記し、数値を書き換えない。
- （公開版には含めない）確認カード.html / img/：家の探し方カード。地図・航空写真の出典は国土地理院（地理院タイル）、建物は国土交通省 Project PLATEAU（東京都練馬区 2025年度）。

## 点群による屋根推定と発電量の検証（2026-11-03）

- （公開版には含めない）roof_validation.csv：練馬区50軒について、東京都の航空レーザー点群（区部点群データ）から推定した屋根の面と発電量を、PLATEAU LOD2 の屋根（No.1〜30）と東京ソーラー屋根台帳の予測値と比べたもの
- 計算条件：屋根の端から0.5m内側にパネルを置く／10m²で1kW／総合設計係数0.85／対象面は傾き3度未満の面と東〜南〜西向きの面（屋根台帳と同じ）／日射量は PVGIS-ERA5 の標準年（開発用）／周りの建物と木の影は半径60mの点群から計算

| グループ | 年間日射量の比（点群÷屋根台帳） | ±15%以内 | 容量の比 | 発電量の比 |
|---|---|---|---|---|
| A 駅前中心（No.1〜30） | 中央値 0.91 | 14/23 | 1.19 | 1.08 |
| B 低層住宅地（No.31〜40） | 中央値 0.99 | 9/10 | 1.11 | 1.09 |
| C 将来の影の候補（No.41〜50） | 中央値 0.97 | 6/9 | 0.88 | 0.83 |

- 屋根の傾き（PLATEAU LOD2 との比較、No.1〜30）：誤差の中央値 1.3°、5°以内 21/30 軒。5°を超えた家は、点群（約50点/m²の実測）と LOD2（航空測量からの模型）のどちらが実際に近いかは決められない
- 屋根台帳と向きの判定が逆になった家：No.2、22、49。点群では南側が高く（北向きの屋根）、パネルの対象面がない。屋根台帳は「適」で日射量が高い。要確認（別の面や建物を対象にしている可能性）
- 駅前（A）で日射量が低めに出るのは、南側の高い建物の影を1時間ごとに計算しているため（例：No.6 は南の空が45〜49°の高さまでふさがっている）

## 将来の影（2026-11-03）

- future_shade_all.json：50軒について、南側（方位100〜260°、30m以内）の建物が「建ててよい最大の高さ」まで建て替わったときの年間発電量の変化
- 建ててよい最大の高さ＝次のうち最も低いもの：容積率÷建ぺい率の階数×3m／用途地域の高さの上限（第1種低層住居専用地域は10mなど）／高度地区の最高限度（PLATEAU 都市計画決定情報 練馬区 2025年度）。斜線制限・日影規制は含めない「最大の目安」
- 発電量が10%以上減る家：A（駅前中心）に多い。最大は No.6 の −62%（商業地域、7階相当まで建てられる）。C の No.46 は −31%（南側が今7m→最大15m）
- 第1種低層住居専用地域の家は、南隣が建て替わってもほとんど変わらない（高さの上限10mのため）

## 日射量を NEDO METPV-11 に差し替え（2026-11-04）

- 日射量を PVGIS-ERA5 から NEDO 年間時別日射量データベース（METPV-11、東京 44132、1990〜2009年の平均年）に差し替えた。水平面の年間全天日射量は 1,250 kWh/m²（PVGIS は 1,367）
- 屋根台帳との日射量の比（中央値）：A 0.80、B 0.88、C 0.84。発電量の比：A 1.00、B 0.96、C 0.73
- 日射量が1割ほど低めになるのは、データの時期（METPV-11 は 1990〜2009年、屋根台帳は気象庁 2013〜2022年）と、散乱光の割合が大きいこと（周りの建物・木で空がふさがれた分の減り方が大きい）によると考えられる
- 差し替え前の結果は roof_validation.csv の git の履歴に残っている
