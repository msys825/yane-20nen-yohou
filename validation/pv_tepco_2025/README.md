# 発電量の答え合わせ：東京電力エリアの実際の発電と比べる（2025年）

このツールと同じ式（傾いた面の日射 × 総合設計係数 0.85）で、2025年の実際の日射量から発電を計算し、東京電力エリアの太陽光の実際の発電と比べた。すべて公開データ。

| | このツールの計算 | 実際の発電 |
|---|---|---|
| 1年間（1kWあたり） | 1,381 kWh | 1,276 kWh（計算の 92%） |
| 1時間ごとの動きの相関 | r = 0.993 | |
| 1日ごとの動きの相関（365日） | r = 0.988 | |

- 晴れ・曇り・季節の動きはほぼ一致する（相関 0.99）
- 量は、計算が実際より約8%多い。差は春〜夏に大きく（約10%）、秋〜冬は小さい（10〜11月はほぼ同じ）。夏の高温で発電効率が下がる分を、計算が固定の係数（0.85）で扱っているためと考えられる
- 比べたのはエリア全体の平均。面の向き・傾き（真南・20°と仮定）、導入量に入らない非FIT の設備、家で使った分の扱いの違いで、量は1割ほどずれうる。1軒ごとの合い方や、影の計算の確かめにはならない

## データ（公開）
- 実績：東京電力パワーグリッド「エリア需給実績」2025年1〜12月（太陽光発電実績＋太陽光出力制御量、30分値）
- 導入量：資源エネルギー庁「固定価格買取制度 情報公表用ウェブサイト」表A② 都道府県別導入容量（2024年末と2025年末の平均、エリア計 20.3GW）
- 日射量：気象庁「過去の気象データ検索」全天日射量（1時間値）東京・館野・銚子・宇都宮・前橋・甲府
