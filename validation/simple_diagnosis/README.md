# 簡易診断の確かめ（練馬区の全戸建て）

詳しい診断（航空レーザー点群で屋根を測る）は 52 軒だけなので、ほかの家は PLATEAU の建物データだけで計算する「簡易診断」で示す（tools/simple_diagnosis.py）。

## 計算のしかた
- 屋根：PLATEAU の屋根の面積 × 0.045 kW/m² でパネルを置ける量。面は真南・傾き25° と仮定し、1kW あたりの発電は ×0.92（詳しい診断の家の屋根の向きのばらつきに合わせる）
- 今の影：60m 以内の建物の外形と高さ（PLATEAU）から、方位ごとの見上げ角を出す。パネルの高さは屋上より 2m 下。木の影は含まない
- 将来の影：南側（方位100〜260°、30m 以内）で、ルール上いまより 3m 以上高くできる建物を最大の高さにして同じ計算
- 区内の戸建て 114,795 軒を約15秒で計算

## 詳しい診断との比較（46軒、2026-11-05）
| 項目 | 詳しい診断 | 簡易診断 |
|---|---|---|
| 今の影の効き方（中央値、影なしに対する割合） | 0.893 | 0.901（相関 0.92） |
| 将来の減り方の相関 | | 0.95 |
| 「将来1割以上減りうる家」の見分け | | 46軒中45軒で一致 |
| 大きく減る家の減り方（中央値） | −27% | −24%（少し小さめに出る） |

パネルの高さ（屋上から何 m 下か）は 1m・2m・3m を試し、2m が最もよく合った。

## 練馬区全体の結果（戸建て 114,795 軒）
| 南側が最大まで建ったときの発電の減り方 | 軒数 | 割合 |
|---|---|---|
| 1割以上 | 2,244 | 2.0% |
| 2割以上 | 955 | 0.8% |
| 3割以上 | 285 | 0.2% |

簡易診断は大きく減る家の減り方を少し小さめに出すので、実際はこれより少し多い可能性がある。
