# 屋根の20年予報 ― その太陽光、20年後も得ですか？

**街のルールが描く20年後を、建てられる側の家族に。**

PLATEAU の3D都市モデルには、建物の形だけでなく、容積率・用途地域・高度地区といった「建ててよいルール」が1棟ずつ入っています。
屋根の20年予報は、南隣の土地がルール上いちばん高い姿に建て替わったときの影まで計算し、屋根の太陽光の20年の損得を、家の持ち主に中立の立場で伝えます。

PLATEAU AWARD 2026 一般部門 応募作品（東京都練馬区）。

## できること

- **建ちうる未来の街**：練馬区の建物を、ルール上の最大の高さまで伸ばして見せる（いまより高くなりうる建物 24,624棟）
- **区全体の予報マップ**：練馬区の戸建て 114,795軒すべての、今と将来の発電量（簡易診断）。将来1割以上減りうる家は 2,244軒（2.0%）
- **詳しい診断**（52軒）：東京都の航空レーザー点群で屋根の形を測り、周りの建物・木の影と、将来の影を1時間ごとに計算
- **わが家の場合の20年の損得**：暮らし方を選ぶとその場で計算。AI（Claude）が、その家の診断と計算結果を根拠に説明し、質問に答える
- **見積もりを、この家の屋根と比べる**：AI が見積書を読み、市場の相場ではなく、この家の屋根と将来の影の計算と比べる

計算（影・日射・発電量・お金）はすべて決まった式で行い、AI には計算させません。AI は説明・相談・書類の読み取りを担当します。

## 確かさ

- 東京ソーラー屋根台帳（練馬区 50軒）と比べ、今の発電量はほぼ同じ水準（発電量の比 0.96〜1.00）
- 東京電力エリアの 2025年の実際の太陽光の発電と、同じ式で計算した発電を1時間ごとに比べ、相関 0.99（[validation/pv_tepco_2025](validation/pv_tepco_2025/README.md)）
- 全戸の簡易診断は、点群で詳しく診断した 46軒と比べ、「将来1割以上減りうる家」の見分けが 45軒で一致（[validation/simple_diagnosis](validation/simple_diagnosis/README.md)）

将来の影は「南側の建物が、容積率・建ぺい率・用途地域・高度地区で許される最大の高さまで建て替わった場合」の目安です。斜線制限・日影規制・前面道路の幅による制限は含みません。実際にそこまで建つとは限りません。

## 構成

| フォルダ | 中身 |
|---|---|
| `app/` | Web アプリ（Next.js 15、CesiumJS、Claude API） |
| `tools/` | 前処理（Python）：点群からの屋根の計測、影と日射の計算、将来の建物、全戸の簡易診断、答え合わせ |
| `validation/` | 確かさの検証の結果 |
| `docs/` | 発表スライドの元ファイル、動画の台本、録画と編集の手順 |

## 動かす

```bash
cd app
npm install
echo "ANTHROPIC_API_KEY=..." > .env.local   # AI の機能を使うとき
npm run dev
```

公開版（Vercel）では、環境変数 `PUBLIC_DEMO=1`・`NEXT_PUBLIC_PUBLIC_DEMO=1` で、AI の回数制限（`AI_DAILY_LIMIT_PER_IP`・`AI_DAILY_LIMIT_TOTAL`）と、見積書をサンプルだけにする設定が有効になります。

前処理（`tools/`）は、PLATEAU の3D Tiles、東京都の区部点群データ、NEDO の日射量データを各自で入手して動かします（NEDO のデータはリポジトリに含めていません）。

## データの出典

- 建物・都市計画：国土交通省 Project PLATEAU（東京都練馬区 2025年度）
- 屋根・影：東京都デジタルツイン実現プロジェクト 区部点群データ（G空間情報センター、CC BY 4.0）
- 日射量：NEDO 年間時別日射量データベース（METPV-11）東京（計算結果のみを使用。元データは含まない）
- 背景地図：国土地理院（地理院タイル）
- 答え合わせ：東京電力パワーグリッド「エリア需給実績」、気象庁「過去の気象データ」、資源エネルギー庁「固定価格買取制度 情報公表用ウェブサイト」
- 費用・補助・単価：調達価格等算定委員会、東京都（クール・ネット東京）、資源エネルギー庁
- 比較：東京ソーラー屋根台帳（東京都・公益財団法人東京都環境公社）。書き写した値は、権利の関係でリポジトリに含めていません
- AI：Claude（Anthropic）
