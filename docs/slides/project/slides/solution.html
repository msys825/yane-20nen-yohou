2. 自動で計測・計算

屋根の形、今の影、将来の影、発電量

3. AIと一緒に判断

家族ごとの損得と、見積もりのセカンドオピニオン

写真も入力もいらない。計算は確実な処理で行い、AIは聞き取りと説明を担当する。

今回の試作：練馬区の戸建て約11.5万軒すべてで簡易診断（PLATEAUの建物データ）。うち52軒は航空レーザー点群で屋根を測る詳しい診断と検証

使い方は3つのステップです。練馬区の3D地図で家をクリックすると、屋根の形、今の影、将来の影、そして発電量が自動で計算されます。最後に、AIと会話しながら、家族の暮らし方に合わせた20年の損得を確かめ、業者の見積もりも中立の立場でチェックできます。今回の試作では、練馬区の戸建て約11万5千軒すべてで、PLATEAUの建物データだけを使った簡易診断ができます。そのうち52軒は、点群で屋根を測る詳しい診断を行い、簡易診断の確かさもこの家々で確かめました。
