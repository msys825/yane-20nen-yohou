AI①　家族ごとの損得

会話で暮らし方を聞き取り、
20年の損得を「幅」で示す

貫井二丁目の家・3人家族回収20年の損得
今の日当たりが続けば8.2年+29万円
南側が建ち、定期点検もすれば回収できず−33万円

AIは電気代・昼の在宅・電気自動車・人数を聞き取り、計算ツールを呼ぶ。金額と年数は、ツールが返した値だけを使う。

1つ目のAIの役割は、家族ごとの損得です。AIが会話で、月の電気代、平日の昼に家に人がいるか、電気自動車の予定、家族の人数を聞き取ります。4つがそろうと、AIは計算ツールを呼び出し、返ってきた数字だけを使って説明します。この家の3人家族の場合、今の日当たりが続けば8.2年で回収して20年で29万円の得。南側が最大まで建ち、電気代が安めで、国が推奨する定期点検もする場合は、20年では回収できず33万円の損です。パワーコンディショナの交換費や点検費は、国の調達価格等算定委員会の想定値を使っています。1つの点数で断定せず、幅で示します。
