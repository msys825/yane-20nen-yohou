これからの展開です。東京都のPLATEAUと点群データは区市町村が違っても仕様が共通なので、同じ仕組みで都内の約50の区市町村に広げられます。また、前面道路の幅による容積率の制限や、道路斜線・日影規制を計算に加え、「最大の目安」をより現実に近い建て替えの姿にしていきます。さらに、区の補助金の最新情報や、中立の相談窓口に、診断書ごとつなげられるようにしたいと考えています。
