東京ソーラー屋根台帳「ご利用上の注意」より

パネルは20年使うのに、20年の間に南側に建ちうる建物は、誰も計算していない。

東京都には、屋根ごとの太陽光の適性を示す「東京ソーラー屋根台帳」があります。とても良いツールですが、利用上の注意には、データを作った後に周りに建物が建つ影響は反映されていない、と書かれています。パネルは20年使うのに、その20年の間に南側に建ちうる建物の影は、誰も計算していません。ここを埋めるのが、この作品です。
