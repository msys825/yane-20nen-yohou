出典：東京都デジタルツイン実現プロジェクト 区部点群データ（G空間情報センター、CC BY）、国土交通省 Project PLATEAU（東京都練馬区 2025年度）

屋根の形は、東京都が公開している航空レーザー点群から自動で計測します。練馬区のあたりでは1平方メートルあたり約50点あり、屋根の面ごとに傾き・向き・面積が出せます。PLATEAUで屋根の形まで整備されている30軒と比べると、傾きの誤差の中央値は1.3度でした。練馬区の戸建てでPLATEAUに屋根の形があるのは0.15%ですが、点群を使えば、屋根の形のデータがない家でも屋根を測れます。今回の試作では、練馬区の52軒で詳しい診断を行いました。周りの建物や木の影も、同じ点群で計算します。
