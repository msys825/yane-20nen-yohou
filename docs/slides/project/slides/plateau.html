建ててよいルール

用途地域・容積率・建ぺい率・高度地区。建物1棟ずつに付いている

将来の影

南隣を最大の高さまで伸ばし、1年8,760時間の影を計算

最大の高さ＝次のうち最も低いもの：容積率÷建ぺい率の階数×3m ／ 用途地域の高さの上限 ／ 高度地区の最高限度。斜線制限・日影規制は含まない「最大の目安」。

この作品の中心は、PLATEAUが持つ2つの材料の組み合わせです。1つは、練馬区の全18万棟の3Dの形と高さ。もう1つは、用途地域や容積率、高度地区といった「建ててよいルール」が、建物1棟ずつに付いていることです。南隣の建物を、ルール上建てられる最大の高さまで伸ばして、1年分の影を計算します。3Dの形とルールが同じデータの中でつながっているPLATEAUだからこそ、できる計算です。
