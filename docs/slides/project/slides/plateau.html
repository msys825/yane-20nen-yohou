建ちうる最大の高さ：容積率・建ぺい率・用途地域・高度地区（北側からの斜線まで）からの目安

これまで、建物の形は平面の地図で、高さは分かりませんでした。建ててよいルールは都市計画図という別の地図にあり、南隣に何が建ちうるかは、1軒ずつ手で調べるしかありませんでした。PLATEAUでは、練馬区の全18万棟の3Dの形と高さに、容積率や用途地域といったルールが1棟ずつ付いています。だから、南隣が建ちうる最大の高さを求め、その影を、区内すべての家で計算できます。
