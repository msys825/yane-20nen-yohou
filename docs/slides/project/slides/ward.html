簡易診断：周りの建物の外形と高さ（PLATEAU）から影を計算。木の影・屋根の形は含まない（屋根は真南・傾き25°と仮定）。大きく減る家は少し小さめに出る

練馬区の戸建て11万4千8百軒すべてについて、今と将来の発電量を計算しました。将来の影で発電が1割以上減りうるのは2,244軒、2パーセントです。大通り沿いなど、ルールが変わる境目の近くに集まっています。逆に言えば、98パーセントの家は、将来の影の心配がほとんどなく、安心して付けられます。全戸の計算はPLATEAUの建物データだけを使う簡易診断で、点群で詳しく診断した46軒と比べると、1割以上減りうる家の見分けは45軒で一致しました。
