建ちうる未来の街

練馬区が、ルールいっぱいに建て替わったら

24,624棟

区内18万棟のうち13%が、いまより3m以上高くなりうる。大通りに沿って、帯のように並ぶ

今と同じ敷地に、建ぺい率いっぱい・容積率で許される階数まで建て替えた場合（1階3m）。用途地域・高度地区の上限も考慮。斜線制限・日影規制・前面道路の幅による制限は含まない目安。出典：国土交通省 Project PLATEAU（東京都練馬区 2025年度）

これは練馬区の、いまの街です。もし、すべての建物が、容積率や用途地域といったルールで許される、いちばん高い姿に建て替わったら。オレンジは、ルール上いまより3メートル以上高くなりうる、2万4千6百棟です。区の建物の13%にあたり、大通りに沿って帯のように並んでいます。いまの地図を見ても、この「建ちうる未来の街」は見えません。
