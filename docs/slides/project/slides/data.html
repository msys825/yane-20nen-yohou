使ったデータは、すべて公的なオープンデータです。建物の形と高さ、そして建ててよいルールはPLATEAUから。屋根の形と周りの影は東京都の航空レーザー点群から。日射量はNEDOの標準気象データから。費用や補助金、売電の単価は、国と東京都の公表資料から取っています。精度の確かめには、東京都のソーラー屋根台帳と、東京電力エリアの実際の発電、気象庁の日射量を使いました。
