自分の土地に、どこまで建てられるか

開発会社・設計者向けの建築ボリュームの検討サービス（国内外に多数）

屋根の20年予報：建てられる側

隣の土地に何が建ちうるか、それで自分の家の20年はどうなるか

家の持ち主のための、中立の予報

土地にどこまで建てられるかを調べる道具は、国内外に数多くあります。ただし、どれも開発会社や設計者のための、建てる側の道具です。屋根の20年予報は、それを裏返します。南隣の土地のルールから、そこに何が建ちうるかを計算し、自分の家の屋根の20年がどうなるかを、家の持ち主に中立の立場で伝えます。
