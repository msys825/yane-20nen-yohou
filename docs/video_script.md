# 3分動画の台本（屋根の20年予報）

- 長さ：3分以内（目標 2分50秒）
- ナレーション：合計 約900文字（1分あたり約300文字）
- 画面：アプリの操作の録画（docs/record_scenes.js で自動撮影）＋スライドの一部
- 数字はすべて、NEDO METPV-11 で計算し直した値（2026-11-04）
- 冒頭の2軒は、練馬区の独立住宅 約11.5万軒の全件から探した（tools/find_pair.py → eval_pairs.py → pair_visuals.py）。用途地域・容積率は練馬区「ねりまっぷ」の都市計画情報でも確認（家A側：第一種住居地域 60/300・高さ20m、家B側：第一種低層住居専用地域 60/150・高さ10m）

## 撮影のメモ

- 録画は 1600×900、2倍の解像度。ブラウザは Playwright の Chromium（WebGL のため headed）
- AI の返答は 20〜40 秒かかるので、録画では待ち時間を編集で詰める
- 動画の書き出しは MP4（H.264）。仮編集は docs/make_rough_cut.sh（ffmpeg）で自動でつなぐ（約2分32秒、AIの待ち時間は削除済み）
- 仮のナレーションは Mac の読み上げ（Kyoko）。提出版は自分の声で録り、narr/01.aiff〜09.aiff を差し替えて同じ手順で書き出す
- 見積書は架空の会社のサンプル（画像に「サンプル」「架空」と明記）
